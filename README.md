# OlehDev — Developer Portfolio

A personal portfolio platform built with Python and Django.

OlehDev is a web application where visitors can explore projects, review technical skills, and submit ideas for future projects. The platform also includes an administrative area for managing portfolio content and handling incoming requests.

## Features

- **Portfolio:** browse projects and view their details.
- **Skills:** explore technical skills and technologies.
- **Project ideas:** submit ideas and suggestions for future projects.
- **User accounts:** registration and login.
- **Request management:** review and manage submitted requests.
- **Admin dashboard:** manage projects, skills, and incoming requests.
- **Responsive interface:** a clean design for a better browsing experience.

## Tech Stack

- **Python**
- **Django**
- **SQLite** for local development
- **HTML5**
- **CSS3**
- **Git and GitHub**

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/o7111023-pixel/OlehDev.git
cd OlehDev
```

### 2. Create a virtual environment

Windows:

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
```

### 3. Install dependencies

If the project contains `requirements.txt`:

```bash
pip install -r requirements.txt
```

If dependencies are managed through another file, use the project's configured dependency manager.

### 4. Apply database migrations

```bash
python manage.py migrate
```

### 5. Start the development server

```bash
python manage.py runserver
```

Open http://127.0.0.1:8000/ in your browser.
